BX / UX / CX 是什麼？ 不是強弱等級，是三種不同的產品線。
BX
Basic Line｜基本線

金屬製 Launcher Hook，重量平衡較穩定；就是最基本的 X 世代結構。

UX
Unique Line｜特色線

改用樹脂 Launcher Hook，把更多金屬配置到外周，讓每顆的特性更突出。

CX
Custom Line｜客製線

上蓋可拆成 Lock Chip＋Main Blade＋Assist Blade，再自由混搭。

例：CX-01 是商品系列編號；1-60 是 Ratchet 零件代碼；R / H / FB 是 Bit 軸心代碼。三種不要混在一起看。
